⚙️ Setting up workflows

After you install the app, open it from your desktop. The main screen shows your current workflows. To create a new one, click the Add button. You select a source folder where your files currently live. Then, choose a destination folder where the app should move them. You can pick settings to run these tasks on a set schedule, such as every hour or every day.

The app keeps a log of all actions. You can check this log if you need to verify that your files moved correctly. If a transfer fails, the app alerts you with a notification.

❓ Frequently asked questions

Does the app delete my original files? No, you decide if the app moves or copies your files. If you choose Move, the software deletes the original file after it creates a copy in the new location.

Can I use this for network drives? Yes, the software works with any folder that Windows can see, including network locations and external hard drives.

Is my data safe during the transfer? The app verifies that files arrive at the destination before it finishes the task.
